# WinnerAds

موقع لاكتشاف المنتجات والإعلانات الوينر في السوق المصري، وبيوصلك بالمورد على تليجرام.

## كيف يعمل

- **البحث** (`/api/search`): كاش أولًا، ثم SearchAPI لميتا وScrapeCreators لتيك توك. البحث الجديد يخصم نقطة، والمتكرر خلال مدة الكاش مجاني. الزائر له 3 عمليات بحث يوميًا.
- **الحفظ** (`src/lib/ingest.ts`): كل إعلان يُحفظ في جدول `ads` مع المعلن وتقييمه.
- **الموردون** (`src/lib/telegram.ts`): مزامنة القنوات العامة من `t.me/s/<channel>` واستخراج السعر من النص. القنوات تُضاف من `/admin/data`.
- **المهمة اليومية** (`/api/cron/daily`): مزامنة الموردين، والسحب الليلي للكلمات، وصفحات المنافسين المتابعة، وتنبيهاتهم، والتذكيرات بالبريد.
- **الأدمن**: `/admin` للباقات والتقييم، و`/admin/users` للعملاء، و`/admin/data` لحالة الربط والقنوات والكلمات.
- قبل ربط مصادر البيانات تظهر بيانات تجريبية بعلامة واضحة.

## التشغيل على الجهاز

```bash
npm install
npm run dev
```

المتغيرات المطلوبة كلها في `.env.example`.
