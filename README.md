# WinnerAds

موقع لاكتشاف المنتجات والإعلانات الوينر في السوق المصري، وبيوصلك بالمورد على تليجرام.

## اللي شغال دلوقتي

- كل الشاشات من التصميم. الإعلانات والموردين لسه داتا تجريبية لحد ما نوصّل مصادر السحب.
- حسابات وتسجيل دخول من Supabase، وصفحة "حسابي" فيها الباقة والنقاط والمدفوعات.
- الباقات وأوزان معادلة الوينر وأرقام حاسبة الربح بتتعدل من لوحة الإدارة `/admin` وبتتحفظ في قاعدة البيانات.
- لوحة الإدارة بتفتح للحسابات اللي `role = admin` بس.
- حاسبة الربح `/calculator` والمحفوظات `/saved`.
- الدفع بـ Paymob جاهز ومقفول لحد ما المفاتيح تتحط في Vercel (شوف `.env.example`). الاشتراك والنقاط بيتفعلوا تلقائي من الـ webhook، ومحتاج `SUPABASE_SERVICE_ROLE_KEY`.

## التشغيل على الجهاز

```bash
npm install
npm run dev
```

## الخطوات الجاية

1. مصادر الداتا الحقيقية: SearchAPI وApify وScrapeCreators وتليجرام.
2. تفعيل Paymob بالمفاتيح وتفعيل الاشتراك من الـ webhook.
