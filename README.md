# WinnerAds

موقع لاكتشاف المنتجات والإعلانات الوينر في السوق المصري، وبيوصلك بالمورد على تليجرام.

## المرحلة الحالية (1 من 3)

- كل الشاشات من التصميم شغالة بداتا تجريبية: الرئيسية، والبحث، وتفاصيل الإعلان، وأفضل المنتجات، والمعلنين، والموردين، والباقات، ولوحة الإدارة.
- معادلة الوينر في `src/lib/score.ts`.
- الدفع بـ Paymob جاهز في الكود ومقفول لحد ما المفاتيح تتحط (شوف `.env.example`).
- لوحة الإدارة `/admin` مقفولة بكلمة سر من `ADMIN_USER` و`ADMIN_PASSWORD`.

## التشغيل على الجهاز

```bash
npm install
npm run dev
```

## الخطوات الجاية

1. Supabase: الحسابات، والاشتراكات، والنقاط، وإعدادات الأدمن.
2. مصادر الداتا الحقيقية: SearchAPI وApify وScrapeCreators وتليجرام.
3. تفعيل Paymob بالمفاتيح وتفعيل الاشتراك من الـ webhook.
